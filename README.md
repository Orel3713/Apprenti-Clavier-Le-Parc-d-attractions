# Apprenti Clavier le Parc d’attractions

![Logo d’Apprenti Clavier le Parc d’attractions. Au premier plan, deux mains tapent sur un clavier surmonté d’un œil vert. Apprenti Clavier le Parc d’attractions est une application macOS accessible proposant des jeux de dactylographie dans l’univers coloré d’une fête foraine.

Elle complète l’application Apprenti Clavier et permet de mettre en pratique la frappe au clavier AZERTY de manière ludique.

## Entrer dans le Parc

Pour entrer dans le Parc d’attractions, l’utilisateur importe un profil provenant d’Apprenti Clavier.

Ce profil doit avoir terminé les quatorze modules d’apprentissage afin de garantir que les exercices proposés correspondent aux connaissances acquises.

Chaque profil conserve séparément sa progression dans les jeux.

## Les jeux du Parc

La version 1.0 propose plusieurs jeux de dactylographie accessibles :

- Défi éclair ;
- Dictée audio ;
- Jeu des ballons ;
- La Grande Roue ;
- Sans faute.

Chaque jeu possède ses propres règles, objectifs et niveaux. Les niveaux se déverrouillent progressivement en fonction des réussites du joueur.

## Accessibilité

L’accessibilité fait partie intégrante d’Apprenti Clavier le Parc d’attractions.

L’application est conçue pour fonctionner avec VoiceOver et propose notamment :

- des intitulés et des annonces adaptés au lecteur d’écran ;
- une navigation pensée pour être utilisée entièrement au clavier ;
- des retours sonores permettant de suivre les actions et la progression ;
- des commandes permettant de réécouter les éléments à saisir ;
- des fenêtres « Comment jouer » accessibles pour chaque jeu ;
- une interface visuelle colorée utilisable sans lecteur d’écran ;
- une apparence automatique, claire ou sombre.

## Prérequis pour l’utilisation avec VoiceOver

Pour utiliser Apprenti Clavier le Parc d’attractions avec VoiceOver, il est nécessaire de connaître les commandes de navigation de base de VoiceOver :

- VO + Flèche gauche et VO + Flèche droite pour parcourir les éléments ;
- VO + Espace pour activer l’élément sélectionné ;
- les commandes d’interaction de VoiceOver pour entrer dans les zones de défilement, les parcourir et en sortir.

L’application s’appuie sur la navigation standard de VoiceOver. Ces connaissances de base sont donc nécessaires pour parcourir correctement son interface.

## Profils et progression

La progression dans les jeux est enregistrée séparément pour chaque profil.

L’application permet notamment de changer de profil, d’importer un profil provenant d’Apprenti Clavier et de réinitialiser la progression dans les jeux.

## Configuration requise

Apprenti Clavier le Parc d’attractions nécessite macOS 12 Monterey ou une version ultérieure.

L’application est prévue pour les Mac équipés d’un processeur Intel ou Apple Silicon.

## Télécharger Apprenti Clavier le Parc d’attractions

Les versions publiques d’Apprenti Clavier le Parc d’attractions sont proposées dans la section « Releases » de ce dépôt GitHub.

Lorsqu’une version est disponible, téléchargez le fichier DMG correspondant, puis ouvrez-le pour accéder à l’application.

L’application intègre également un système de mise à jour utilisant Sparkle.

## Documentation

Un Guide utilisateur accompagne Apprenti Clavier le Parc d’attractions et présente en détail l’installation, l’importation des profils, la navigation dans le Parc, les règles des jeux, les réglages, les raccourcis utiles et les solutions aux problèmes les plus courants.

## À propos de ce projet

Je suis moi-même déficient visuel et j’ai souhaité créer un espace ludique permettant de mettre en pratique les connaissances acquises dans Apprenti Clavier.

Apprenti Clavier le Parc d’attractions a été pensé aussi bien pour les personnes utilisant VoiceOver que pour les personnes n’utilisant pas de lecteur d’écran. Les retours sonores, les annonces accessibles et les éléments visuels permettent à chacun de suivre les jeux et sa progression.

Ce projet est avant tout une activité personnelle réalisée sur mon temps libre. Je ne suis pas développeur professionnel. Pour concevoir et développer l’application, je me suis notamment appuyé sur des outils et des agents d’intelligence artificielle, qui m’ont accompagné dans sa réalisation technique.

J’espère que cette application pourra vous permettre de vous entraîner agréablement et de découvrir la dactylographie sous une forme différente.

Les signalements de problèmes et les suggestions sont les bienvenus. Je ferai mon possible pour y répondre et améliorer l’application lorsque cela m’est possible. Toutefois, n’étant pas développeur professionnel, je ne peux pas garantir de pouvoir apporter une assistance technique approfondie ni résoudre tous les problèmes rencontrés.
